# DocAvail

DocAvail is a comprehensive, full-stack healthcare appointment scheduling platform designed to bridge the gap between patients and healthcare providers. This project was developed as an academic mini-project to demonstrate real-time database management, user role-based access, and modern web application features.

## ⚠️ Important Disclaimer
**This application is an independent student project developed for academic purposes.** * **Affiliation:** This project is not affiliated with, endorsed by, or sponsored by any hospital, clinic, or medical entity listed. 
* **Data Usage:** Real hospital names and locations are used solely to demonstrate the functionality of the "Emergency Mode" and geolocation features. All doctor profiles, clinic information, and appointment availability data are **fictitious/simulated**.

## 🚀 Overview
DocAvail enables patients to find, filter, and book appointments with nearby hospitals and independent clinics. It features a robust dashboard system for providers to manage their doctor listings and availability.

## 🛠 Features
- **Patient Portal:** Search and filter doctors by specialty, distance, and real-time availability.
- **Provider Dashboards:** Separate portals for Hospitals and Independent Clinics to manage doctors and time slots.
- **Smart Search & Filters:** Efficiently sort and filter medical services.
- **Accessibility:** Integrated Voice Search and GPS emergency location mode.
- **Secure Authentication:** Role-based login system for Patients, Hospitals, and Clinics.

## 💻 Tech Stack
- **Frontend:** HTML,CSS,Vanilla JavaScript
- **Backend:** Node.js,Express
- **Database:** MongoDB Atlas
- **Deployment:** Render

## 🔗 Live Demo

## ⚙️ How to Run Locally
1. Clone this repository: `git clone <your-repo-url>`
2. Install dependencies: `npm install`
3. Set up environment variables (ensure your MongoDB URI is configured).
4. Start the server: `npm start`
